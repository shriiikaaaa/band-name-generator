# Band Name Generator 🎸

A simple beginner Python project that generates a possible band name based on the user's city and pet's name.

## 📌 About the Project

The Band Name Generator asks the user for their city and the name of their pet. It then combines both inputs to create a potential band name.

This is one of my first Python projects and focuses on learning the basics of user input, variables, and string manipulation.

## ⚙️ How It Works

The program:

1. Asks the user which city they are from.
2. Asks the user for their pet's name.
3. Stores both answers in variables.
4. Combines the two values.
5. Displays the generated band name.

## 💻 Example

```text
Welcome to the Band Name Generator!
Which city are you from? Mumbai
What is the name of your pet? Bruno

Your band name could be: Mumbai Bruno
```

## ▶️ How to Run

Make sure Python 3 is installed on your computer.

Open the terminal in the project folder and run:

```bash
python3 band_name_generator.py
```
