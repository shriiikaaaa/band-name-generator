# Band Name Generator 🎸

A simple beginner Python project that generates a possible band name based on the user's city and pet's name.

## How It Works

The program asks the user for:

- Their city
- Their pet's name

It then combines the two inputs to generate a possible band name.

## Example

```text
Welcome to the Band Name Generator!
Which city are you from? Mumbai
What is the name of your pet? Bruno

Your band name could be: Mumbai Bruno
```
## Concepts Used
print()
input()
Variables
String concatenation

## How to Run
Make sure Python is installed on your computer.

Run:
```python3 band_name_generator.py```
